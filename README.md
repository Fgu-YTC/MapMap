# MapMap

Merlin Chain Bitmap 儀表板與可拼接大地圖。

## 線上預覽

https://Fgu-YTC.github.io/MapMap/

## 本機開發

```bash
cp .env.example .env
# 填入 Particle Network 的 Project ID / Client Key / App ID
npm install
npm run dev
```

## 功能

- Particle BTC Connect AA 錢包連線
- Bitmap ERC-721 持倉儀表板
- 可平移縮放的拼接地形大地圖
- Merlin Address Explorer
